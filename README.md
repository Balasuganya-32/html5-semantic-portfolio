# Personal Portfolio Website

A fully accessible and semantic multi-page portfolio website built using HTML5 and CSS.

## Features

- Semantic HTML5 structure
- Accessibility-friendly design
- ARIA labels and roles
- SEO optimized meta tags
- Keyboard navigable contact form
- Responsive layout

## Pages

- Home
- About
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3

## Accessibility

This project follows modern HTML5 semantic standards and WCAG accessibility guidelines.
